# AI-Powered Waste Classification System ♻️

An intelligent image classification system that uses Deep Learning to identify waste as either Recyclable or Organic. The project aims to support efficient waste segregation and promote environmentally sustainable waste management practices.

## Overview

Waste segregation is a crucial step in recycling and environmental conservation. This project leverages Convolutional Neural Networks (CNNs) to automatically classify waste images into different categories, reducing manual effort and improving sorting accuracy.

## Features

- Image-based waste classification
- Deep Learning model built using CNN architecture
- Image preprocessing and augmentation
- User-friendly web interface for image uploads
- Real-time prediction results
- Model performance evaluation using classification metrics

## Dataset

The model was trained on a labeled dataset containing images of:

- Recyclable Waste
- Organic Waste

Dataset preprocessing included:

- Image resizing
- Normalization
- Data augmentation
- Train-test splitting

## Model Architecture

- Convolutional Layers
- Max Pooling Layers
- Fully Connected Layers
- Softmax Output Layer

## Results

- Achieved approximately 85% classification accuracy on the test dataset.
- Successfully identified waste categories from unseen images.
